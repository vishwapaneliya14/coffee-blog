# ☕ BrewAtlas — Coffee Explorer & Recipe Blog

A frontend Web Application Development project built with **HTML5, CSS3 and JavaScript**.

## Features
- Coffee types from around the world
- Coffee recipes
- Coffee travel destinations
- Things to do at each destination
- Search and filtering
- Wishlist using browser `localStorage`
- Login and registration UI
- JavaScript form validation
- Contact form validation
- Responsive design
- Online images, so no image folder is required
- GitHub Pages friendly
- No backend/database required

## How to run
1. Download/clone the repository.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. To publish: upload the complete folder to GitHub and enable **Settings → Pages**.

## Technologies
HTML5 • CSS3 • JavaScript • localStorage

## Academic note
This is a frontend-only demonstration. Login/account data and wishlist are stored locally in the browser and are not connected to a real database.
